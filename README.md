# DDRegistrateCorrespondence
Описание API (название контроллера\имя метода):
RegCor\CheckAdminsInRecievers - Серверный метод проверяющий наличие администраторов среди получателей. Данные на вход - массив id сотрудников
RegCor\GetAdminsSecritarID  - Серверный метод возвращающий идентификатор секретаря администрации
RegCor\GetOriginalSameComplaintDate  - Серверный метод получения оригинала жалобы и отправки уведомления на почтовую группу "жалобы дд" если жалоба сама оригинальна. Данные на вход - id карточки
RegCor\NotifyPersonsAndGroups  - Серверный метод уведомления персон и групп в соотвтествующих полях. Данные на вход - id карточки
RegCor\SetCardFolder  - Серверный метод установки папки карточки (реализация изменена, теперь не требутся). Данные на вход - id карточки
RegCor\AddNewDocumentType  - Серверный метод добавления нового вида документа в справочник. Данне на вход - id карточки, имя нового типа документа
RegCor\GetAllDictionaryRows  - Серверный метод получения всех строк узла конструктора справочников. Данне на вход - id узла конструктора справочников
RegCor\CreateReplyLink - Серверный метод Создания обратной ссылки ответ. Данне на вход - id карточки
